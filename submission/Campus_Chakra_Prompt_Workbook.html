2. Prompt iteration log

IterationRepresentative promptDecision / outcome
Schema & constraints“Inspect all P2P dataset tables and map their fields to the problem constraints. Identify late data, aliases and unit conflicts.”Defined validation, normalization, deduplication and traceable ingestion rules.
Waste classification“Compare sensor-only and edge-available feature sets; retain a model that meets the accuracy and latency constraints.”Selected compact forest deployment with explicit sensor-quality features and offline inference.
Forecasting“Benchmark 6h and 12h demand forecasts on chronological holdout; document accuracy / footprint trade-offs.”Selected lightweight forecasting bundle and exposes forecast outputs in the API.
Operational copilot“Ground every recommendation in supplied telemetry, event context and operator notes; supply a deterministic fallback.”Implemented evidence-led recommendations without making external LLM availability critical.

3. Human contribution and safeguards

  • Defined the edge-first architecture, measurable success criteria and evaluator workflow.
  • Specified idempotent reconciliation for delayed gateway transmissions.
  • Chose fairness-aware, building-normalized incentive logic rather than raw consumption comparisons.
  • Added input schema validation so jury uploads fail clearly rather than silently producing invalid results.
